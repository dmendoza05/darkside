Host these pages and poke the extension.

Each page is one fixture. This home page is a normal light site, so Dark Mode should invert it. Photos on the other pages have known colors so a missed un-invert is obvious.

How to host

From the repo: cd test && ./serve.sh (or python3 -m http.server 8765). Open http://127.0.0.1:8765, load the unpacked extension, then walk the cases.

1. Dark theme

Already-dark pages should skip invert. Popup hint should appear. Includes luminance, data-theme, and class variants.

2. Images

Photos stay true-color: img, picture, canvas, background-image, and SVG with a raster. Icons and SVG files follow the page invert.

3. Presets

Soft, Night, Sunset, Contrast, and Reading only move brightness, contrast, warmth, and dim. They do not turn invert on.
