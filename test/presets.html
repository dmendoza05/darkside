Presets only tune the eyes, not invert.

Open the popup on this tab. Click Soft, Night, Sunset, Contrast, then Reading. Invert should not flip on by itself. Use this page with Dark Mode off first so the sliders are easy to see.

Pass if

Each preset moves brightness, contrast, warmth, and dim to the values below, and the matching chip in the popup lights up. The cream page does not suddenly invert unless Dark Mode is already on. Reset this site returns to global defaults.

Expected slider values

Preset Brightness Contrast Warmth Dim Look for
Soft 100% 100% 15 0 Almost neutral, slight warmth
Night 85% 105% 45 25 Dimmer, amber, slightly punched
Sunset 95% 100% 70 10 Strong sepia / orange cast
Contrast 105% 135% 8 0 Inkier type, harder edges
Reading 92% 110% 35 8 Soft paper, mild warmth

Reading sample

The harbor lamps came on before the sun had fully gone. Warmth in the filter should make this paragraph feel like cheap paper under a bulb. Contrast should make the letters bite. Dim should feel like someone lowered the room, not like the ink went gray.

Night is the heaviest: less brightness, more warmth, a real dim overlay. Sunset is the orange one. Soft is the control — if Soft and the global default look identical, check that warmth actually moved from 20 to 15.

Warmth strip

Sepia stacks on these oranges. Sunset should look almost brown-gold.
